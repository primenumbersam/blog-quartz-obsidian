> 정의는 '정의(正義, justice)'와 '정의(定義, definition)'로 구분되며, 전자는 도덕, 법률, 사회적 맥락에서 사용되고, 후자는 과학, 수학, 프로그래밍 등에서 사용된다. justice는 공정성과 관련이 있으며, definition는 개념과 명제의 명확화를 목표로 한다.



|  | 정의 (正義, justice) | 정의(定義, definition) |
| --- | --- | --- |
| **한자 의미** | 正(바를 정) + 義(의로울 의) | 定(정할 정) + 義(뜻 의) |
| **영어** | justice, righteousness | definition |
| **주요 사용 분야** | 문과, 도덕, 법률, 사회, 철학 등 | 이과, 형식적 수학, 프로그래밍, 과학, 논리학 등 |
| **반대말/대조어** | 부정(不正), 불의(不義), 비리 | 무정의(無定義, undefined) |
| **주요 사용 예** | 부정부패(不正腐敗) = '불공정·비리와 타락'<br>불공정(不公正)<br>정의로운 재판<br>사회정의 구현 | 숫자 a + b = b + a 로 +의 교환법칙을 정의한다<br>힘 F는 m×a로 정의한다<br>함수를 정의하다<br>변수를 정의하다 |
| **추가 예시** | 정의사(正義士) - 의로운 사람<br>정의감<br>불의(不義)에 항거하다<br>천부정의(天賦正義) | 용어를 정의하다<br>개념 정의<br>클래스를 정의한다<br>정의역(domain) |
| **관련 개념** | 공정(公正), 공평(公平), 정직(正直) | 개념(concept), 명제(proposition), 공리(axiom) |
| **사용 맥락** | 도덕적·윤리적 판단<br>사회적 가치 평가<br>법적 판단 기준 | 학술적·기술적 설명<br>논리적 명확화<br>프로그래밍 구현 |
| **추상성** | 가치판단적, 실질적 | 구체적, 형식적 |

> Clean and Clear Language는 명확하고 투명한 언어로, 관측 가능하고 반박 가능하며 재현 가능한 데이터를 강조한다. 반면, Fuzzy and Foggy Language는 모호하고 불투명한 언어로, 관측 불가하고 책임이 확산되는 경향이 있다.



---

언어공학자인 Quant Hacker가 선호하는 언어는 Clean and Clear Language

비교표 
- Clean and Clear Language (명료하고 투명한 언어, CC language)
- Fuzzy and Foggy Language (모호하고 불투명한 언어, FF language)

| Clean and Clear Language | Fuzzy and Foggy Language |
| --- | --- |
| 관측 가능 observable | 관측 불가 latent |
| 반박 가능 falsifiable | 반박 불가 non-falsifiable |
| 재현 가능 reproducible | 사후 구성 post hoc |
| 책임 귀속 가능 accountability | 책임 확산 diffusion |
| 실전적 survival data | 정치적 framing |
| 현실 구조를 이해하기 위한 언어 | 권력의 책임을 숨기기 위한 언어 |
| 현실을 설명하고 생존을 도움 | 현실을 은폐하고 책임을 제거 |

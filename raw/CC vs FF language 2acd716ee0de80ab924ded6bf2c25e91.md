# CC vs FF language

번역어: Clean&Clear vs Fuzzy&Foggy
Created time: November 15, 2025 5:22 PM
Description: Clean and Clear Language는 명확하고 투명한 언어로, 관측 가능하고 반박 가능하며 재현 가능한 데이터를 강조한다. 반면, Fuzzy and Foggy Language는 모호하고 불투명한 언어로, 관측 불가하고 책임이 확산되는 경향이 있다. 두 언어의 예시와 의미 차이를 통해 이들 간의 구분이 명확히 드러난다.

---

언어공학자인 Quant Hacker가 선호하는 언어는 Clean and Clear Language

- Clean and Clear Language (명료하고 투명한 언어, CC language)
- Fuzzy and Foggy Language (모호하고 불투명한 언어, FF language)

예시 대비

| Clean and Clear Language | Fuzzy and Foggy Language |
| --- | --- |
| • Inflation (인플레이션): 가격 수준의 변화율, CPI로 관측
• Employment (고용률): 취업자 수 비율
• Exchange rate (환율): 실시간 시장 가격
• Yield curve (수익률 곡선): 채권 금리 구조
• Volatility (변동성): 통계적으로 측정되는 분산값
• Drawdown (고점대비 하락률): 뚜렷한 실측 데이터 | • Potential growth rate (잠재성장률)
• Output gap (산출 갭)
• Natural interest rate (자연이자율, r*)
• NAIRU (자연실업률)
• Trend productivity (추세 생산성)
• Market equilibrium (시장균형)
• Rational expectation (합리적 기대)
• Complete market (완전시장) |

의미 대비

| Clean and Clear Language | Fuzzy and Foggy Language |
| --- | --- |
| 관측 가능 observable | 관측 불가 latent |
| 반박 가능 falsifiable | 반박 불가 non-falsifiable |
| 재현 가능 reproducible | 사후 구성 post hoc |
| 책임 귀속 가능 accountability | 책임 확산 diffusion |
| 실전적 survival data | 정치적 framing |
| 현실 구조를 이해하기 위한 언어 | 권력의 책임을 숨기기 위한 언어 |
| 현실을 설명하고 생존을 도움 | 현실을 은폐하고 책임을 제거 |

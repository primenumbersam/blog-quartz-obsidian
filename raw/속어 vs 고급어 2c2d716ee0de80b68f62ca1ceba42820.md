# 속어 vs 고급어

번역어: 낮은 시선
Created time: December 8, 2025 12:50 AM
Description: 속어는 대중 담론과 감각적 사고를 반영하며, 고급어는 엘리트 담론과 분석적 사고를 강조한다. 속어는 직설적이고 즉각적인 메시지를 전달하는 반면, 고급어는 깊이 있는 사유와 논리적 구성을 중시한다. 가치 지향에서도 속어는 이익 중심, 고급어는 진리와 윤리를 중시한다.

“속어는 쓰되 논문처럼 사고하라.”

| 구분 | 저급·싸구려·통속 계열 | 고급·세련·교양·전문 계열 |
| --- | --- | --- |
| 사회적 코드 | **대중 담론, 유행어, 일상어, 자극어** | 엘리트 담론, 학술 담론, 공적 언어 |
| 화법 스타일 | **노골적, 직설적, 속어체** | 고급어(高級語), 세련, 품격 있는 어휘 |
| 사고 방식 | 단편적, 감각적, 피상적, 주관적 | **분석적, 구조적, 비판적, 통찰적, 객관적** |
| 글쓰기 | 감정 과잉, 산만한 구성, 직설적 과장 | **절제된 은유, 논리적 구성, 맥락 중심, 함축적 서술** |
| 메시지 성격 | 즉각적, 표면적, 소비 중심 | **깊이 있는, 구조적, 사유 중심** |
| 가치 지향 | 이익·선동·쾌락 중심 | **진리·탐구·윤리 중심** |
